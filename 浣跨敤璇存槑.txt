EasyDownload 使用说明
====================

【这是什么】
一个用 C# + WPF 写的下载器，界面仿 WinUI 3 风格（圆角、卡片、深浅主题），
内核是 WebView2（跟 Edge 一样，不是 IE，必应图片和脚本都能正常跑）。
不需要 WindowsAppRuntime，不需要 UWP，不需要 Python，Win10 就能跑。

【怎么用】
1. 解压到一个全新的空文件夹（不要覆盖旧目录）
2. 用 Visual Studio 打开 EasyDownload.csproj
3. 等 NuGet 还原完成（需要装 Microsoft.Web.WebView2 这一个包）
4. 按 F5 运行

【首次启动】
会弹 4 步引导：欢迎 → 选浅色/深色 → 下载设置 → 开始使用。
点完「开始使用」后，设置会存起来，第二次启动不再弹。

【界面】
- 首页：多标签网页（新建标签 / 关闭 / 后退 / 前进 / 刷新），地址栏输入网址回车
  在网页里点下载，会自动交给下面的下载器接管
- 下载：粘贴文件链接 → 新建下载；支持开始 / 暂停 / 继续 / 打开 / 删除
  多线程最高 32 线程，带进度条、实时速度、已下载大小
- 设置：主题、线程数（1-32）、同时下载数、自动限速、断点续传、下载前询问、下载目录

【标题栏】
右上角：太阳/月亮图标 = 切换深浅主题，然后是最小化 / 最大化 / 关闭。

【如果网页打不开】
说明电脑缺 WebView2 运行库，装这个（普通安装程序，跟装 QQ 一样）：
https://go.microsoft.com/fwlink/p/?LinkId=2124703
装完重启程序即可。Win10 最新系统一般自带。

【注意】
- 只支持 HTTP / HTTPS 直链下载，不支持 BT 磁力
- 断点续传要在设置里打开「启用断点续传」
- 下载文件默认存在 用户目录\Downloads
